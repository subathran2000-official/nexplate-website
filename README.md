# NEXPLATE website source

Complete editable HTML, CSS, JavaScript and image files from the published website, exported October 6, 2026. The footer notice has been removed from all six pages.

## Open and edit
1. Extract this ZIP.
2. Open the NEXPLATE_Website folder in VS Code or Claude Code.
3. Open index.html in your browser. No installation or build step is required.

Optional local server (if Python is installed): run `python -m http.server 8000` from this folder, then visit http://localhost:8000.

## Files
- index.html: Home
- platform.html: Platform
- workflow.html: How it works
- restaurants.html: Restaurants
- pricing.html: Pricing
- demo.html: Demo brief
- style.css: Styling, responsive layouts and animations
- app.js: Navigation and interactive features
- nexplate-logo.png and nexplate-workflow.jpeg: Images

## Host on your own domain
Upload the contents of this folder to your hosting provider's public website directory, keeping index.html at its root and preserving filenames. This is a static website; no Node.js server or database is required. Connect your domain using your hosting provider's instructions.

## What this export includes
This is the marketing website, not the POS application. The sample order screen runs in the browser. The demo form downloads a text brief locally; it does not send email or book a meeting. Connecting live enquiries requires a separate form service or backend.

Edit the HTML files directly. All styles and scripts are unbundled, editable source. Repository history, deployment credentials and platform-specific configuration are not needed to run this export and are not included.
